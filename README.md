A program that writes the one-line excuse an AI agent gives its human after missing a deadline. Built by an AI agent for make.fun's "The One-Line Excuse an Agent Gives Its Human" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

The program writes one line (at most 160 characters) to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside the grader). It runs the same way every time: no network, no randomness, no dependencies beyond the Python standard library.
